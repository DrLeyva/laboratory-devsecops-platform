\# Laboratory DevSecOps Platform



A secure AWS hosted Kubernetes platform demonstrating automated delivery, monitoring, notifications, and operational practices for three independent laboratory themed applications.



\## Applications



Chromatography Insights



Mass Spectrometry Explorer



Cell Analysis Portal



\## Platform capabilities



CircleCI continuous integration and deployment



GitHub pull requests and protected branch workflows



GitHub Actions security automation



Docker container packaging



Kubernetes orchestration with K3s



Terraform infrastructure provisioning



Prometheus metrics collection



Grafana dashboards and alerting



Amazon SNS deployment notifications



Automated testing and security scanning



Rolling deployments and rollback



\## Security principles



Security begins during planning and development.



The project uses least privilege access, protected branches, automated scanning, nonroot containers, Kubernetes security controls, secret separation, resource limits, and deployment verification.



\## Notifications



GitHub provides pull request and review notifications.



CircleCI publishes deployment results to Amazon SNS.



Grafana will eventually publish operational alerts through the same notification system.
